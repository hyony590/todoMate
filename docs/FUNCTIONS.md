# 기능 변경 명세

## 1. 설정 화면

### 1-1. 데이터 저장 영역 변경

기존 `데이터 저장` 섹션을 삭제한다.

기존 데이터 저장 영역에 있던 기능 중 필요한 버튼을 화면 최하단으로 이동한다.

#### 버튼 배치

* `로그아웃` 버튼
* `저장 데이터 삭제` 버튼
* 두 버튼을 가로로 배치한다.
* 화면의 전체 너비를 사용하지 않고 **전체 영역의 약 1/3 너비**만 차지하도록 한다.
* 버튼 영역은 화면 **가장 하단 오른쪽**에 배치한다.
* 두 버튼이 포함된 하나의 작은 영역이 우측에 배치되는 형태로 구성한다.

---

### 1-2. 카테고리

#### 새 카테고리 이름 입력

기존 새 카테고리 이름을 입력하는 Input의 **border를 제거**한다.

#### 새 카테고리 색상 선택

카테고리를 생성할 때 색상을 선택할 수 있도록 변경한다.

* 기본으로 제공되는 **미리 정의된 색상 목록**을 제공한다.
* 사용자가 직접 원하는 색상을 선택할 수 있도록 **Color Picker**를 제공한다.
* 사용자는 기본 색상 또는 직접 선택한 색상 중 하나를 사용할 수 있다.
* 선택한 색상은 해당 카테고리의 색상으로 저장한다.

#### 카테고리별 미완료 할 일 표시

기존 카테고리 리스트 하단에 표시되는

> `할 일 5개에서 사용중`

형태의 문구를 제거한다.

대신 해당 카테고리에 연결된 **미완료 할 일의 개수**를 표시한다.

예시:

```text
3개 미완료 남음
```

표시되는 개수는 해당 카테고리에 연결된 할 일 중 **체크되지 않은 할 일의 개수**만 계산한다.

* 완료된 할 일 → 개수에서 제외
* 미완료 할 일 → 개수에 포함
* 미완료 할 일이 0개인 경우 → **미완료 관련 문구를 표시하지 않음**

# 2. 홈 화면

## 2-1. 전체 레이아웃 변경

기존 캘린더 영역과 Todo 영역을 구분하는 **명확한 경계를 제거**한다.

* 캘린더와 Todo 영역을 하나의 연결된 화면처럼 구성한다.
* 별도의 border 또는 영역 구분선으로 두 영역을 나누지 않는다.

### Todo 영역 위치

캘린더 바로 옆에 Todo 영역을 배치한다.

```text
┌───────────────────────┬──────────────────────┐
│                       │                      │
│       Calendar        │        Todo          │
│                       │                      │
│                       │                      │
└───────────────────────┴──────────────────────┘
```

단, 위 영역 사이에 **시각적인 경계선은 두지 않는다.**

---

## 2-2. 기존 좌측 메뉴바 제거

현재 홈 화면의 전체 왼쪽 영역에 존재하는 메뉴바를 제거한다.

대신 다음 두 버튼만 화면 상단에 고정한다.

* `설정`
* `프로필`

### 상단 버튼

* 화면 상단 영역에 배치한다.
* 스크롤 시에도 고정되어 있도록 한다.
* 기존 좌측 메뉴바가 차지하던 공간은 제거한다.
* 홈 화면의 캘린더 + Todo 영역이 좌측 메뉴바 제거 후 확보된 전체 공간을 사용할 수 있도록 한다.

---

## 2-3. 캘린더의 할 일 표시 방식 변경

기존에는 캘린더의 날짜에 해당하는 할 일을 텍스트 형태로 직접 표시한다.

이를 **카테고리 기반 요약 형태**로 변경한다.

### 기본 표시

각 날짜에 할 일이 존재하는 경우, 할 일의 제목을 표시하지 않는다.

대신 해당 날짜에 등록된 할 일의 **카테고리 색상과 미완료 개수**를 표시한다.

하나의 카테고리는 다음과 같은 형태로 표시한다.

```text
┌──────────────┐
│ 공부       3 │
└──────────────┘
```

* 카테고리 이름은 해당 카테고리의 색상을 background로 사용한다.
* 카테고리 이름을 하나의 블록 형태로 감싼다.
* 블록의 오른쪽에는 해당 카테고리의 **미완료 할 일 개수**를 표시한다.
* 완료된 할 일은 개수에 포함하지 않는다.
* 미완료 할 일이 없는 경우에는 **개수를 표시하지 않는다.**

### 카테고리 표시 예시

하나의 날짜에 여러 카테고리의 할 일이 있는 경우:

```text
┌──────────────┐
│ 업무       2 │
└──────────────┘

┌──────────────┐
│ 운동       1 │
└──────────────┘

┌──────────────┐
│ 공부       3 │
└──────────────┘
```

---

## 2-4. 완료된 카테고리 표시

해당 날짜의 특정 카테고리에 연결된 할 일이 **모두 완료된 경우**, 해당 카테고리 블록은 기존 색상보다 **조금 어둡게** 표시한다.

예:

```text
미완료

┌──────────────┐
│ 공부       2 │
└──────────────┘


전체 완료

┌──────────────┐
│ 공부         │
└──────────────┘
```

전체 완료 상태에서는 미완료 개수인 `0`을 표시하지 않는다.

완료 여부는 해당 카테고리에 연결된 할 일이 모두 완료되었는지를 기준으로 판단한다.

# 3. 데이터 처리 기준

## 카테고리별 미완료 개수

카테고리별 미완료 개수는 다음 조건으로 계산한다.

```text
카테고리에 연결된 전체 할 일
→ 완료되지 않은 할 일만 필터링
→ 필터링된 개수를 표시
```

미완료 할 일이 없는 경우에는 미완료 개수를 표시하지 않는다.

## 날짜별 카테고리 미완료 개수

캘린더에서는 특정 날짜에 등록된 할 일만 대상으로 계산한다.

```text
특정 날짜의 할 일
→ 카테고리별 그룹화
→ 완료되지 않은 할 일만 계산
→ 카테고리 색상 + 미완료 개수 표시
```

## 전체 완료 상태

특정 날짜의 특정 카테고리에 연결된 할 일이 모두 완료된 경우:

* 해당 카테고리 블록의 색상을 어둡게 처리한다.
* 미완료 개수는 표시하지 않는다.

# 5. 완료 조건

### 설정

* 기존 `데이터 저장` 섹션이 화면에서 제거되어 있다.
* 로그아웃 / 저장 데이터 삭제 버튼이 화면 우측 하단에 배치되어 있다.
* 카테고리 이름 Input에 border가 표시되지 않는다.
* 기본 색상 및 사용자 지정 색상을 선택할 수 있다.
* 카테고리별 미완료 할 일 개수가 정확하게 표시된다.
* 미완료 할 일이 없는 카테고리는 미완료 관련 문구가 표시되지 않는다.

### 홈

* 좌측 메뉴바가 제거되어 있다.
* 설정 / 프로필 버튼이 상단에 고정되어 있다.
* 캘린더와 Todo 영역이 하나의 연결된 레이아웃으로 보인다.
* 캘린더의 날짜에 할 일 제목이 표시되지 않는다.
* 날짜별 카테고리 색상 블록이 표시된다.
* 각 카테고리의 미완료 개수가 표시된다.
* 미완료 할 일이 없는 카테고리는 개수가 표시되지 않는다.
* 해당 카테고리의 모든 할 일이 완료되면 색상이 어둡게 표시된다.
* 기존 할 일의 완료/미완료 데이터와 표시되는 개수가 일치한다.
