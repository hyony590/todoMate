# Supabase 설정

1. SQL Editor에서 `schema.sql` 전체를 새 쿼리로 한 번 실행합니다. 기존 동일 이름 테이블이 있으면 실행하지 말고 구조를 먼저 확인합니다.
2. Authentication → URL Configuration: Site URL 및 Redirect URLs에 `http://127.0.0.1:5173`과 배포한 Vercel 주소를 등록합니다.
3. 앱에서 이메일·비밀번호로 가입하고 확인 메일을 누른 후 로그인합니다. 비밀번호는 앱에 직접 입력하며 개발자에게 전달하지 않습니다.
4. 개인 계정 가입을 마쳤다면 Authentication 설정에서 신규 가입 허용을 끄는 것을 권장합니다. 로그인은 계속 가능합니다.
5. Vercel 환경변수에 `.env.example`의 두 이름으로 Project URL과 Publishable key를 설정하고 재배포합니다. Secret/service_role 키는 사용하지 않습니다.

할 일과 카테고리에 RLS를 적용합니다. 사용자별 조회/수정/삭제가 제한되며 다른 계정의 카테고리를 연결할 수 없습니다. 기본 카테고리는 가입 시 생성됩니다. 테마·주 시작 요일은 기기별 로컬 설정입니다.

기존 localStorage 할 일/카테고리는 자동 업로드하거나 삭제하지 않습니다. 클라우드에서는 새 데이터로 시작합니다. 이관이 필요하면 별도 이관 기능을 준비합니다.

검증: 서로 다른 두 계정에서 데이터가 분리되는지, 로그아웃 상태에서 REST 조회가 불가능한지 확인합니다. 저장 데이터 삭제는 현재 계정의 클라우드 데이터에 적용됩니다.
