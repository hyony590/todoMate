# 하루

TodoMate의 편안한 일일 계획 경험에서 영감을 받아 만든 개인용 플래너입니다. 브랜드와 에셋은 복제하지 않고, 날짜 중심의 빠른 할 일 관리 흐름을 독자적으로 구현했습니다.

## 실행

```bash
npm install
npm run dev
```

## 현재 기능

- 월간 날짜 이동 및 월요일/일요일 주 시작 선택
- 월간 캘린더와 날짜별 할 일 미리보기
- 카테고리별 할 일 목록
- 카테고리 추가, 이름·색상 수정, 안전한 삭제
- 할 일 추가, 완료, 삭제, 텍스트 클릭 후 단일 항목 수정
- 스크롤 제스처별 한 달 이동 및 날짜별 카테고리 3개 + 나머지 개수 표시
- 습관 생성(매일/요일별 반복)과 날짜별 독립적인 완료 기록
- 캘린더의 선택 날짜에서 카테고리별 할 일 추가·완료·삭제
- 플젝하루 캘린더의 각 프로젝트 옆 등록 버튼에서 Todo/일정을 바로 등록 (해당 프로젝트와 선택 날짜 기본 적용)
- 확인 절차를 거치는 로컬 데이터 초기화
- Sharp, Soft, Midnight 테마 전환
- 반응형 데스크톱/모바일 UI
- Supabase 연결 시 이메일 로그인 및 사용자별 할 일·카테고리 저장
- 환경변수 미설정 시 브라우저 로컬 저장

## Supabase 연결

UI는 할 일과 카테고리를 각각 Repository 인터페이스로 분리해 사용합니다. Supabase 환경변수가 설정되면 클라우드 구현체와 로그인 화면을 사용합니다. 기존 로컬 데이터는 자동 이관·삭제하지 않습니다.

필요한 환경변수 이름은 `.env.example`에 준비되어 있습니다. 실제 값은 git에서 제외되는 `.env.local`에 설정합니다. 테이블·RLS 정책은 `supabase/schema.sql`, 설정 절차는 `supabase/SETUP.md`를 참고하세요.

Update #2를 사용하려면 기존 프로젝트에 `supabase/update-2.sql`을 한 번 실행합니다. 새 프로젝트는 `schema.sql` 실행 후 적용하세요. 이 마이그레이션 자체는 기존 할 일/카테고리를 삭제하지 않습니다. 습관 테이블과 날짜별 완료 테이블은 RLS로 계정별 분리하며, 카테고리 삭제 RPC는 연결된 할 일과 카테고리를 한 트랜잭션에서 삭제합니다. 데이터 초기화 버튼은 습관 기록도 초기화합니다.

검증: `npm run build`와 `node scripts/update-2-tests.cjs`. 저장소 테스트는 메모리 기반 로컬 저장소를 사용하므로 실제 계정 데이터에 접근하지 않습니다.
